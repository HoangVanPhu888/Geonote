================================================================================
                    GeoNote Studio - Windows Desktop Application
================================================================================

HOW TO RUN THE APPLICATION ON WINDOWS:

Method 1 (Immediate / Recommended):
----------------------------------
1. Open the folder:
   dist-electron\win-unpacked\

2. Double-click:
   GeoNote Studio.exe

That's it! The full dynamic geometry and LaTeX note-taking application will launch
in its own standalone Windows desktop window.

Alternative Launchers:
---------------------
- You can also double-click "Launch-GeoNote-Studio.bat" located in the root of this folder.
- If you wish to build an installer (.exe) or modify code, run "build-windows-exe.bat".

FEATURES INCLUDED:
------------------
- Scrble note-taking with Pen, Highlighter, and Eraser.
- Geometer's Sketchpad & GeoGebra tools:
  * Circles & Lines (Circumcircle, Incircle, Excircle, Euler's Line, Nine-point Circle, Mixtilinear circles, Radical Axis)
  * Transformations (Translation, Rotation, Inversion with Circle, Dilation, Polar lines, Isogonal lines)
  * Triangle Centers (Centroid, Circumcenter, Orthocenter, Incenter, Excenter, Lemoine, Gergonne, Nagel, Euler Center)
  * Conic Sections (Ellipse, Parabola, Hyperbola with 5-point and focus/directrix methods)
- Changeable point size and line thickness down to 1 (hairline).
- Angle shading and angle styles (Sector, Hatch, Arcs, Right-angle).
- Live LaTeX typesetting with KaTeX and math symbol presets.
- Continuous scroll A4 pages with left thumbnail navigation and Word-style zoom (50%, 75%, 100%, 150%).
- High-resolution multi-page PDF export for teaching materials.
