                    GeoNote Studio - Windows Desktop Application

Why is the downloaded project zip ~10 KB?
------------------------------------------
In AI Studio, code export archives only download the raw source code text files
(~10 KB). Large pre-compiled binary executables (.exe files, 150+ MB) are not
shipped inside the git source download to keep the repository lightweight.

HOW TO RUN OR CREATE THE .EXE ON YOUR WINDOWS PC (EASY 1-CLICK):
---------------------------------------------------------------

Option 1: Launch Desktop App Directly (Fastest)
-----------------------------------------------
1. Make sure Node.js is installed on your PC (https://nodejs.org).
2. Double-click:
      run-windows.bat
3. The app will install necessary components and open directly into a native
   Windows desktop window!

Option 2: Generate the Standalone "GeoNote Studio.exe" File
---------------------------------------------------------
1. Double-click:
      make-exe.bat
2. It compiles the project and packages the 64-bit Windows executable.
3. Your executable will be waiting at:
      dist-electron\win-unpacked\GeoNote Studio.exe
   You can double-click this .exe anytime to run offline!

Option 3: Zero Installation Desktop App (PWA)
---------------------------------------------
1. In your web browser (Microsoft Edge or Google Chrome), open the app.
2. In the top address bar on the right, click the "App Available / Install" icon
   (or click Menu ... -> Apps -> Install GeoNote Studio).
3. Windows will immediately install a native standalone .exe application
   on your Desktop and Start Menu without any build steps!
